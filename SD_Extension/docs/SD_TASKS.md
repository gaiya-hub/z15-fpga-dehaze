# SD与串口批处理操作

本流程使用SD传输图像，每批经JTAG初始化一次，PS_UART显示进度，处理后由读卡器导入完整结果。电脑负责解码、缩放和帧参数准备，板卡执行双ARM统计及PL去雾计算。

## 准备和运行

1. 先完成[构建](BUILD.md)，准备FAT32 microSD/TF卡、读卡器、电源、JTAG及PS_UART连接。
2. 双击launch_sd.cmd，打开SD任务窗口。选择有雾图片文件夹，首轮建议用2至5张图。
3. 点击“导出SD任务”，保存位置选择卡的盘符根目录，例如E盘。程序自动创建DEHAZE，并生成INDEX.BIN、TASK.JSON、IN和OUT。原卡已有DEHAZE时，先归档整个旧目录，再导出新任务。已有归档会继续占空间。
4. 导出前程序估算输入、输出、计时记录及余量，空间不足时停止准备。输入BIN是板卡使用的打包像素文件，通过程序导入查看结果。
5. 安全弹出读卡器，板卡断电插卡，保持JTAG启动模式。接好PS_UART与JTAG后上电。
6. 在SD窗口选择PS_UART对应的COM口，以115200连接，点击“一次初始化并启动SD批处理”。程序配置本目录的位流和固件，启动双核并读取卡上任务。
7. 等待串口SD_BATCH_DONE，或查询完成状态确认结束。运行期间由同一任务持有板卡锁。
8. 完成后断电取卡，用读卡器接电脑，点击“导入SD完整结果”，选择卡上的DEHAZE。程序检查CRC、任务与模型标记后恢复图片、计时和评价结果。

## 数据与任务组织

输入使用IN/I0000001.BIN等8.3文件名，输出图像为OUT/O0000001.BIN，逐图记录为R0000001.BIN，批次结束写BATCH.BIN。原始文件名与GT配对由TASK.JSON管理。当前SD流程为顺序处理，开启新任务前保留旧结果，任务中断后按新批次重新准备。

程序不会格式化或改分区。存储规划按处理后输入与输出BIN大小计算，不能只按压缩JPG容量估算。图像在处理完成并导入后显示，处理期间由串口提供进度。

## 时间范围

算法合计为电脑帧参数加板上稳定计算。SD读取及输入校验、输出写入、输出CRC、首图预热与CPU1启动分别记录。整批计时包含挂载、索引读取、CPU1启动等待、预热、所有计算、SD读写、逐图记录及串口进度，不含最后BATCH.BIN自身写入、初始JTAG配置、电脑导出导入和搬卡。

已完成的两图板级结果见[SD_ACCEPTANCE.md](SD_ACCEPTANCE.md)，操作方案不包含SD启动镜像、网络实时图片回传或原生JPG解码。

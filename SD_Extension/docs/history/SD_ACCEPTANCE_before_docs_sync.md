## 你们独立操作的入口

项目主目录新增“启动SD卡演示.cmd”和“查看SD实测结果.cmd”。前者打开原三图布局及SD任务窗口；后者载入最近一批已核验的SD结果。原launch.cmd和原正式双核固件保留。

SD流程：导出任务到卡根目录DEHAZE → 安全弹出 → 板卡断电插卡并保持JTAG启动拨码 → 打开SD演示、连接PS_UART串口 → 点击一次初始化并启动 → 等SD_BATCH_DONE → 断电取卡接读卡器 → 导入SD完整结果。

开启新批次前，先将旧DEHAZE目录改名归档，再准备新的DEHAZE；首版不会覆盖已有输出，也不支持断电续跑。当前电脑可见分区约130MB，足够本次两图；大批量之前需要另行规划可用存储空间，当前未改分区或原系统文件。

这不是SD上电自启动；没有BOOT.BIN更新，也没有网口图片回传、摄像头连续视频或功耗实测。

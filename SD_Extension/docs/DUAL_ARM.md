# 双ARM局部统计

本页描述SD_Extension当前实现。ARM0与ARM1使用私有16行环形缓存处理上下分区，以全图坐标计算15×15反射边界统计，按对齐分界协同准备19项局部特征。像素数不能被8整除、高度小于16或无合适分界时回退ARM0。

## 启动与同步

SD批处理在首图前启动CPU1，后续图像复用已启动工作核，按任务描述符协同完成统计。每批仅首图预热，启动与预热在批次记录中单独计入。

固件编译包含firmware/dual_entry.S，构建脚本从ELF提取CPU1入口并生成匹配协议，位流、ELF和协议按当前方案配套。

## 优化与输出

相对单ARM版本，三个尺寸的板上计算耗时分别为496.89→483.33 ms（640×360）、487.38→473.98 ms（548×412）及5281.78→5144.24 ms（1920×1280）。该组对比采用每图预热1次、测量5次，保持算法、位流和模型一致。局部统计约快29%，完整板上计算降低约2.6%至2.8%，最终输出逐像素一致。

该组实验来自JTAG主线的双核优化验证。本目录SD读写实验另见[SD_ACCEPTANCE.md](SD_ACCEPTANCE.md)，不可把JTAG实验时间直接当作SD完整批次时间。

算法合计、初始化、数据传输与独立评价的范围见[CURRENT_VERSION.md](CURRENT_VERSION.md)。

# Z15去雾工程操作流程

本目录记录本项目实际使用的构建与验证步骤，供复现使用；不是对竞赛技能模板合规性的声明。

1. 输入：选定JTAG或SD分支的源码、冻结模型、Vivado/Vitis 2024.2和匹配板卡资料。
2. 离线：读取BUILD.md，配置本机路径；导出参数并检查激活范围；构建native参考，核对边界尺寸。
3. 构建：HLS导出IP，Vivado集成并完成布线，检查资源和时序；从当前XSA生成BSP并编译固件与匹配协议。
4. 上板：核对BIT、ELF与协议哈希；检查启动目标，运行真实输出，逐像素比较独立参考，保留失败和恢复证据。
5. 计时：分离参数、板上计算、初始化、传输、验证；预热后重复计时，同时报告样本和范围。
6. 发布：剔除工具链、BSP、数据集和本机设置；运行离线测试，检查压缩包；明确未完成能力。

停止条件：像素不一致、计时器不连续、资源超限或时序失败时，不将该候选晋升为正式演示版本。保留旧版和失败证据。

# 演示流程

JTAG_Mainline作为交互演示入口，展示设备连接、初始化、选择成对图片、板卡处理、三图放大、质量指标和电脑同算法比较，再展示2至3张图片的顺序批处理。

SD_Extension展示保存的两图实卡结果与进度记录，明确图片经SD读写、结果在处理后导入。现场是否搬卡按演示安排决定，历史结果标明其记录来源。

录制中将计算、传输和初始化时间分项说明，等待片段如经剪辑应注明。完成源码发布后展示实际仓库主页与构建说明。仓库状态见[PUBLISH.md](PUBLISH.md)，当前算法和实验范围见[CURRENT_VERSION.md](CURRENT_VERSION.md)。

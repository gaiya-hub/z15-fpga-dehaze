# 演示界面更新

首页移除“成对样例”“历史实测”，启动时等待用户选图。已有数据与历史记录不删除。

“三图同步放大”：鼠标滚轮围绕指针缩放；按住左键拖动；双击适合窗口；可点100%回到原生比例。支持原生Windows触屏捏合、单指平移，以及系统映射为Ctrl+滚轮的缩放。是否能收到真实触屏手势取决于设备和驱动；窗口底部显示检测情况。每次只渲染可见区域，不把整张图片放大成巨型位图。

底部“电脑/FPGA同算法对比”：先完成当前图片FPGA处理，再重新测电脑同算法。仅比较相同输入、尺寸、参数的同一算法，不运行FFA-Net或外部自适应算法。增强V2与旧版模式都支持；不一致时显示错误并保留记录。

电脑预热1次、平均3次。表格分开列参数估计、像素计算、算法合计和JTAG上传/回读。FPGA来自所选处理记录，并非点击对比后再次上板。新记录额外计时电脑参数估计；旧记录缺这一时间时，算法合计和计算比明确标记为估算。计算比不是含文件读写和JTAG的整批加速比。

此更新不改变FPGA内核和现有算法，也没有加入去雾神经网络。批处理入口保留。

Windows手势接口依据：https://learn.microsoft.com/en-us/windows/win32/wintouch/wm-gesture

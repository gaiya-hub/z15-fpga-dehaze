# 增强V2演示与选择理由

重新打开 launch.cmd，初始化板卡，底部选择“自适应增强（V2）”，选择有雾图后运行。三图为配对无雾参考、有雾输入、真实FPGA回读。可以切换旧版柔和或旧版增强复测。旧窗口需关闭后重新打开，以加载新代码。

拍摄时先说明旧版在浓雾下残雾明显；同图切换V2，展示细节与指标；再展示ARM/FPGA同算法计算时间。软件对比窗口展示原始FFA-Net CPU输出与原有自适应暗通道，不能把不同算法的速度差说成FPGA加速比。

选择V2的理由是两图组平均画质均改善、115/134张PSNR优于旧版，同时能以整数运算实际部署到小型Zynq器件。V2不是神经网络，完整FFA-Net尚未上板。natural公共16张FFA仍更好，不能宣称全面超越网络。天空等失败图仍需继续改进。

新算法的硬件步骤：两路15×15暗通道；强分支1/4尺度导向滤波；Q12系数与双线性恢复；范围约束；原处理分辨率RGB恢复与融合。电脑只估计空气光与融合权重，不使用GT调参。

质量统计统一最长边640，已查看图集只作回归。新板上时间与旧版约11倍记录分别标明；JTAG传输时间单列。尚未完成摄像头连续视频链路、持续FPS与功耗测量。

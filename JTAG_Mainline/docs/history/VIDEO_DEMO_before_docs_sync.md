# 三分钟内演示顺序

| 时间 | 展示 | 说明 |
|---|---|---|
| 0:00–0:20 | 电脑、Z15、电源、JTAG、PS串口全景 | JTAG用于加载和传图；串口用于日志；尚无摄像头连续视频输入 |
| 0:20–0:45 | 初始化与输入选择 | 默认板上V3；GT只评价，不能参与去雾 |
| 0:45–1:25 | 一次真实去雾 | 最终图来自FPGA回读，不能将电脑生成图标成FPGA输出；等待若加速剪辑要标明 |
| 1:25–1:55 | 三图同步放大、PSNR/SSIM/MAE | 显示真实细节和当前图片指标；不宣称0.90已实现 |
| 1:55–2:25 | 电脑/FPGA同算法对比 | 展示电脑完整Q14算法与板卡实际记录，分别说明优化ARM统计、32路PL神经、JTAG传输；速度如实报告 |
| 2:25–2:45 | 批量任务/汇总 | 明确逐张真实上板；保存结果与计时，支持停止续跑 |
| 2:45–2:55 | 源码、结构、构建与许可证 | 无GitHub仓库时只能称本地源码包已整理，不能称已公开发布 |

神经推理和防失真保护在PL，局部统计在板上ARM（16行环形缓存、NEON及整数修正）；电脑只算帧参数和独立校验。不要宣称网络全部计算都在PL，也不要把JTAG单图流程称实时视频。

录制不需要聊天助手：双击launch.cmd独立运行。按提交页面要求，MP4/H.264，3分钟内，300MB以内；避免学校名、指导老师姓名等无关身份信息。不要用聊天截图替代原生图像展示。

双核版本演示：重新初始化后处理图片，指出ARM0/ARM1分担统计、PL推理保持不变。单列双核启动与JTAG耗时；不宣称两倍加速、稳定快于电脑或画质因双核提高。

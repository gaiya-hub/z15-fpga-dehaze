# 优化V3使用与执行位置

默认单图及批处理已切换为“优化V3（FPGA＋电脑神经校正）”。原来的自适应增强V2与旧版暗通道仍可在下拉框选择。

## 实际执行流程

有雾图片 → 电脑估计帧参数 → JTAG传给Z15 → FPGA执行双分支暗通道/快速导向滤波/范围约束/融合 → 回读并与独立定点参考校验 → 电脑生成神经网络需要的辅助强分支/透射率/局部均值方差 → 电脑CPU运行轻量神经校正与颜色范围保护 → 显示最终图。

神经网络尚未部署到FPGA或板上ARM。bit与elf仍是已验证的V2硬件版本。V3是硬件与电脑共同处理的系统，不是纯FPGA神经网络去雾。

## 指标与计时

- 三图中的最终结果及PSNR/SSIM/MAE对应完整V3输出。
- `fpga_output.png`：原始、实际的FPGA回读；`hybrid_output.png`：完整V3结果。两者分别保存。
- `result.json`中的`fpga_quality`对应原始回读，`quality.output`对应最终结果；没有GT则画质指标留空。
- FPGA/ARM耗时与“板上DCP比”只描述基础V2；电脑辅助特征＋神经校正＋保护的时间单列。
- 算法计算合计＝电脑帧参数估计＋FPGA基础DCP＋电脑辅助/神经/保护。模型准备、JTAG、文件读写和校验不包含在这个计算比里；全流程耗时另计。不能把基础FPGA耗时当作完整V3时间。
- 底部同算法对比：电脑执行相同的完整V3，与FPGA参与的完整V3比较，最后逐像素核对。V2历史记录仍按V2比较。

## 画质边界

固定134张既有回归、最长边640：V2→防失真V3，平均SSIM0.8499→0.8667，PSNR18.41→20.18dB，MAE25.92→21.64。目标平均SSIM0.90尚未达到；仍有3张相对V2的PSNR下降超过3dB。该版本是用户选择启用的预览优化版，允许切回V2，不承诺逐张提升。

神经校正参数在49张开发图上标定；GT只参与训练/评价，不参与运行时推理或保护规则。详细研究记录位于主工程quality_v3，开源包research/neural_v3保存可复现的离线参考与训练划分，不含数据图片。

## 批处理与启动

主工程启动器仍为launch.cmd。已打开的旧进程需要重新启动才会加载新代码；默认下拉框显示“优化V3（FPGA＋电脑神经校正）”。

批处理默认选择真实FPGA参与；可切换同算法电脑参考或V2。输出文件夹保存最终图；配置记录包含算法、神经权重、保护规则和源码哈希。升级后的版本使用新的输出文件夹，不混用旧任务记录。

保留V2选项是按图比较与回退入口；备份位置记录在本地docs/HYBRID_V3_INSTALL.json。该文件不进入公开源码包。

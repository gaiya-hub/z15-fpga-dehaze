# 文件夹批量去雾

重新双击launch.cmd，点击“批量去雾”。选择有雾图文件夹和独立输出目录，点击“开始/继续批处理”。默认电脑增强算法，适合大量离线图片，不需要板卡。真实FPGA模式自动初始化一次，之后逐张上传、处理、回读与独立参考核对。

处理是自动逐张进行，不是多张同时上板。PC与FPGA使用同一增强V2算法，但PC输出明确标记为软件，绝不冒充硬件结果。大量数据的整批速度目前通常受JTAG限制，不能把FPGA计算时间当作整批端到端时间。

输出images/保留输入相对目录，文件名为“原文件名.原扩展名.dehazed.png”，避免同名jpg/png覆盖；原图不改动。当前保持比例、不放大小图，最长边可选640/1280/1920，并限制最高1920×1280；大图可能缩小，CSV记录原始与处理尺寸。

summary.csv可用Excel打开，含逐张画质、计算时间、JTAG时间、端到端时间和成功/失败信息。无配对GT也能去雾，画质分数留空；自动GT只按已有数据集命名约定匹配，也可选择独立GT根目录并保持相对子目录、同名或去掉_hazy后缀。

“完成当前张后停止”保留已有结果。继续任务时选择同一输出目录、同样输入/模式/尺寸；程序通过模型、源图、GT及输出内容哈希检查后跳过已完成项。损坏/删除的输出会重做，新增输入也会处理。配置变化请用新目录。电脑模式跳过损坏图片继续，真实上板遇错会停下，防止把断线后大量图片都记作成功。

批量上板默认关闭ARM重复基准，且每张只计时1次（底层仍预热1次），始终保留电脑独立计算校验。需要性能对照时勾选ARM基准；它会增加处理时间。默认清理该次处理新生成的大型二进制与重复PNG；PNG成品、批次records、原始result.json和调试日志保留。精简记录不在单图历史页打开。勾选完整硬件调试文件会占用更多磁盘。

命令行：

```powershell
python -B batch_dehaze.py --input "有雾图片目录" --output "独立结果目录" --engine pc --edge 1280
python -B batch_dehaze.py --input "有雾图片目录" --output "另一个结果目录" --engine fpga --edge 1280
```

可选 --gt 无雾根目录、--no-recursive、--arm-benchmark、--keep-debug。电脑与FPGA结果请使用不同的任务输出目录。

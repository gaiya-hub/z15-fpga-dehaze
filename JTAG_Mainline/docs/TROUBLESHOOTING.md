# 初始化错误排查

“未收到硬件初始化标记”只说明没有完成初始化，必须查看 outputs/initialize.log。
若日志包含 `whole scan chain (DR shift through all zeroes)`，当前没有扫描到有效的板上JTAG芯片；不能据此判断为算法、模型或bit文件问题。

1. 先断开板卡电源，再检查灰色排线两端是否插紧、是否插在板上JTAG、1脚对应且没有错排。
2. 确认BOOT_CFG两开关为ON，配套电源接入DC插座并打开板上电源开关，电源指示灯亮。
3. 下载器自身USB接电脑；PS_UART是另一条串口线，不能替代JTAG。
4. 上电后重新点击初始化。仍失败时保存完整日志，并检查下载器USB连接/驱动或更换已确认正常的线缆。

“调试服务已连接”只表示连到电脑上的hw_server，不保证已识别板子。程序仅在确认APU目标后才显示已识别Zynq芯片。
修改代码后需要关闭旧窗口、重新双击launch.cmd，旧进程不会自动加载更新。
